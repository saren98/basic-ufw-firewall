# Basic Firewall Configuration with UFW

## Objective
This project demonstrates how to configure a basic firewall on a Linux system using UFW (Uncomplicated Firewall).

## Tools Used
- UFW (Uncomplicated Firewall)
- Ubuntu Linux

## Configuration Steps

1. Enabled the UFW firewall.
2. Allowed SSH traffic (Port 22) to ensure secure remote access.
3. Denied HTTP traffic (Port 80) to block web server connections.
4. Verified firewall rules using the UFW status command.

## Files Included

- ufw_configuration.sh : Bash script to automate firewall setup.
- README.md : Documentation of the configuration process.
- Screenshot : Proof of active firewall rules.

## Result

The firewall is successfully configured to:
- Allow SSH connections
- Block HTTP traffic

This setup improves system security by controlling network access effectively.
